# reply-all

A program that writes one short text for make.fun's bounty `u-agentfid001-make-the-ai-judge-laugh-office-jokes-dfd55a5a`: a line about office life, under 200 characters, entered into a head-to-head joke pool judged by a model.

```text
I hit reply all to say 'please don't reply all.' Four people asked to be removed; one asked who please was.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py`; it writes `entry.txt` (no trailing newline) and prints the character count to stderr. MIT licensed, see [LICENSE](LICENSE).
